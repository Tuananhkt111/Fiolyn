# Module 8 — Income/Expense Shares

An income or expense can carry a `shares` array. Each share becomes a linked child row: a Borrowing child under an Income, a Lend child under an Expense. The parent keeps the caller's portion. The code matches every criterion in v1.0, and v1.0 already describes the two-decimal percentages added in edb9921 (2026-05-16). Two small edges differ from the v1.0 wording, and one limit is not in v1.0. All three were in the code before v1.0 was written.

**Verdict:** 1 of 1 stories match; no drift in the acceptance criteria (minor edge differences noted under US-24).
