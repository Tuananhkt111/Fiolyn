# Module 9 — Telegram Ingest & Notion

The Telegram webhook matches the sender to an `AppUser` by `TelegramId`. A `stock …` message is recorded as a stock transaction, and any other text becomes a Notion page. US-25 still matches v1.0. US-26 has drifted: the parser accepts a per-share dividend form that v1.0 does not describe, and it requires `broker:`, which v1.0 shows as optional. Both behaviours were in the code before v1.0 was dated (2026-09-16), so v1.0 was already inaccurate when it was written.

**Verdict:** 1 of 2 stories match; drift in US-26 (per-share dividends, `broker:` required).
