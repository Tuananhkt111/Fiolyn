# Module 6 — Transactions

Every money movement is a `TransactionBase` leaf whose signed `Amount` is applied to `SpendAccount.Balance` in one save through `TransactionBalanceWriter.SaveWithConcurrencyGuardAsync`. A concurrent balance write loses with 409 (`[ConcurrencyCheck]` on `Balance`). No service calls `repository.Update(entity)`, and each leaf runs `TransactionCategoryGuard`. No production code in this module has changed since v1.0 (2026-09-16); every difference below already existed when v1.0 was written.

**Verdict:** 5 of 5 stories match. US-19 was Partly: a member of only the destination account could update or delete a transfer. #20 fixed it. US-21's description of "owner/member enrichment" on admin reads did not hold; Rev 3 corrects it.
